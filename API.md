# API

The project is a research prototype, not a clinical service. Laravel routes are under `/api`; the separate FastAPI service runs locally on port `8001` by default. Neither service accepts real patient data. Laravel has no patient write endpoint; Python schemas accept only explicitly marked generated synthetic fixture records.

| Method | Path | Access | Behavior |
|---|---|---|---|
| `POST` | `/api/auth/register` | Public, throttled | Create a research account with a confirmed 12+ character password and issue a bearer token |
| `POST` | `/api/auth/token` | Public, throttled | Verify credentials and issue a Sanctum bearer token |
| `POST` | `/api/auth/logout` | Sanctum | Revoke the current bearer token |
| `GET` | `/api/research/projects` | Sanctum | List caller-owned projects and the shared synthetic demo |
| `POST` | `/api/research/projects` | Sanctum, throttled | Create a caller-owned draft project; writes an audit entry |
| `GET` | `/api/research/projects/{id}` | Sanctum, owner/demo policy | Read a project only if owned or the shared demo |
| `GET` | `/api/research/status` | Public | Research-only scope, data rule, and feature availability |
| `GET` | `/api/research/overview` | Public | Counts for records in datasets explicitly marked `synthetic` |
| `GET` | `/api/research/patients` | Public | Synthetic subject keys and coarse synthetic age band |
| `GET` | `/api/research/patients/{id}` | Public | Ordered event timeline and arbitrary-unit fixture measurements, synthetic datasets only |
| `GET` | `/api/research/experiments` | Public | Most recent stored synthetic experiment runs and computed metrics |
| `POST` | `/api/research/experiments/synthetic-baseline` | Public, throttled | Runs FastAPI fixture experiment and persists returned metrics plus audit entry; returns `503` if analysis is unavailable |
| `POST` | `/api/research/agents/analyze-synthetic` | Public, throttled | Accepts a synthetic subject ID, forwards only its synthetic lab series, and persists seven structured agent runs plus audit entries |
| `POST` | `/api/research/digital-twin/{id}/materialize` | Public, throttled | Builds a state from rows in a synthetic dataset, sends metadata/features without document bodies, and stores the versioned state plus audit entry |
| `GET` | `/api/user` | Sanctum | Authenticated user endpoint generated by Laravel API installation |

FastAPI routes, served only on the local interface by the documented development command:

| Method | Path | Behavior |
|---|---|---|
| `GET` | `/health` | Service status and model availability |
| `POST` | `/v1/research/trajectory-summary` | Validates a synthetic-only trajectory and returns descriptive linear fit statistics |
| `POST` | `/v1/research/digital-twin/materialize-synthetic` | Materializes a versioned synthetic snapshot with modality coverage, uncertainty, and lineage |
| `POST` | `/v1/research/agents/analyze-synthetic` | Returns seven structured workflow-stage results; unavailable evidence/risk stages abstain |
| `GET` | `/v1/research/experiments/synthetic-baseline` | Executes deterministic held-out synthetic baseline and silo-aggregation experiments |

Every response is informational and must not be interpreted as personalized advice. Public Laravel demo routes expose generated fixture records only; records in non-synthetic datasets return `404`. Python outputs are not persisted by the Python service. Laravel persists only the experiment endpoint's returned aggregate metrics and audit metadata.

## Local Setup

From `medtwin-x/`, run `php artisan migrate --seed` and start with `php artisan serve`. Configure a local database in `.env`; MySQL 8+ is the intended environment, and SQLite is used for tests. Start the Python service from `services/ai/` with Uvicorn bound to `127.0.0.1:8001`; Laravel's `MEDTWIN_AI_URL` defaults to that address. Do not expose development services publicly or add secrets to version control.

## Roadmap, Not Available Yet

Project updates/deletion, queues for AI calls, licensed medical evidence retrieval, medical graph population, real NLP/image models, general multimodal learning, formal differential privacy, and production deployment controls are not implemented. FastAPI's structured agent endpoint is deterministic scaffolding, not an LLM multi-agent system. Bearer tokens expire after seven days by default (`SANCTUM_EXPIRATION` minutes).
